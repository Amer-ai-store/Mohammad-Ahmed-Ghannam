اتصل برمز قراءة

اسمح في خدمة المراقبة بأصل اللوحة، ثم أدخل عنوان HTTPS ورمز القراءة في النموذج أعلاه. لا تستخدم رمز إرسال السجلات في المتصفح. تظهر «متصل» بعد استجابة صحيحة فقط، ويمكنك قطع الاتصال لمسح الرمز والسجلات والمواقع من الذاكرة.

للتحقق المحلي فقط يُقبل HTTP على loopback. عنوان localhost يشير إلى الجهاز الذي يفتح المتصفح، وليس إلى JAWAFFASVR أو خادم بعيد.

بديل دون اتصال مباشر

استورد ملف JSON محليًا بالصيغة الموثقة. يُعرض على جهازك فقط، وبوسم «مستورد» واضح، دون رفعه إلى GitHub أو خدمة أخرى.

قراءة عقد الخدمة وصيغة الاستيراد ←

ماذا يمكن أن تُظهر اللوحة؟

  • وقت محاولة الدخول ونجاحها أو فشلها، والحساب المسجّل وعنوان IP إذا توافرت.
  • تسلسل الأحداث المرتبطة بمعرّف جلسة موثّق في المصدر.
  • الأوامر والعمليات فقط إذا سجّلها نظام تدقيق وأُضيف ربط خاص به؛ موصّل SSH لا يجمعها تلقائيًا.
  • موقع تقريبي لعنوان IP عند طلب البحث يدويًا، مع رابط إلى خرائط Google.

حدود تحديد الموقع

عنوان IP لا يكشف عنوان المنزل أو موقع الشخص الدقيق. قد تشير النتيجة إلى مزوّد الخدمة أو VPN، ولا يمكن ضمان اكتشاف العنوان الأصلي خلفه.
