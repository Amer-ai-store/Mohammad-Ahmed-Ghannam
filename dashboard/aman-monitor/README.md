# أمان: واجهة السجلات في لوحة جوافة

هذا المجلد وحدة HTML وCSS وJavaScript مدمجة مباشرة في القيادة المركزية، بلا بناء أو اشتراك AppDeploy. تحافظ الصفحة المضيفة على تسجيل الدخول والتنقل الموجودين فيها. ملفات GitHub Pages نفسها عامة؛ لا تتضمن سجلات الخادم أو رموز الوصول، ولا تمنح مصادقة الصفحة المضيفة صلاحية قراءة خدمة السجلات.

## الاستخدام

1. شغّل خدمة مراقبة خاصة تديرها خلف HTTPS، واسمح بأصل اللوحة في CORS. مصدر الخدمة ودليل تشغيلها في [downloads](./downloads/README.md).
2. أدخل عنوان الخدمة، مثل `https://monitor.example.org/security`، ورمز **قراءة** مخصصًا لها. لا تستخدم رمز إرسال السجلات في المتصفح.
3. تظهر حالة الاتصال بعد استجابة صحيحة من الخدمة. تُحدّث الصفحة كل 3 ثوانٍ أثناء ظهورها وبعد نجاح الاتصال؛ يمكن إيقاف التحديث يدويًا.

يحفظ JavaScript الرمز في ذاكرة الصفحة فقط. لا يُكتب في التخزين المحلي أو تخزين الجلسة أو ملفات المستودع أو عنوان URL. يُمسح حقل الرمز بعد بدء الاتصال. «قطع الاتصال ومسح البيانات» يلغي الطلبات الجارية ويمسح الرمز والأحداث والمواقع والتفاصيل من الذاكرة ومن العرض. مغادرة قسم المراقبة أو تسجيل الخروج أو تغير الحساب يزيل الوحدة ويمسح الجلسة المحلية أيضًا. لا تستخدم الوحدة iframe، ولا تغير تبويباتها رابط القسم المركزي.

يرسل المتصفح الرمز فقط إلى الخدمة التي أدخلت عنوانها. تحقق من العنوان قبل إدخاله. تمنع الطلبات إعادة التوجيه، ولا ترسل ملفات تعريف ارتباط، وتستخدم سياسة `no-referrer` ومهلة 10 ثوانٍ. رفض الرمز بـ401 أو403 يقطع الاتصال ويمسح البيانات؛429 يوقف التحديث التلقائي. عند تعذّر تحديث اتصال قائم يظهر تنبيه بأن الأحداث من آخر استجابة ناجحة.

يُقبل HTTPS للإنتاج. يُسمح HTTP فقط على `localhost` و`127.0.0.1` للتحقق المحلي. يشير loopback إلى الجهاز الذي يعمل عليه المتصفح، وليس إلى JAWAFFASVR أو إلى بيئة بعيدة. يجب ألا يتضمن عنوان الخدمة اسم مستخدم أو كلمة مرور أو query أو hash.

## عقد الخدمة

إذا أدخلت `https://monitor.example.org/security`، تستدعي الصفحة فقط:

```http
GET https://monitor.example.org/security/api/events
Authorization: Bearer <read-token>
Accept: application/json
```

تُحفظ بادئة المسار `/security` ولا يُرسل الرمز في الرابط. يجب أن يجيب طلب CORS المسبق عن سماح `GET` وترويسة `Authorization` لأصل اللوحة المصرح به. لا تكفي الواجهة العامة أو جلسة الدخول في لوحة جوافة لحماية هذه الخدمة؛ تتحقق الخدمة من رمز القراءة على الخادم.

الاستجابة:

```json
{
  "events": [
    {
      "id": "event-unique-within-source",
      "source_id": "server-owned-by-you",
      "session_id": "recorded-session-id-or-null",
      "occurred_at": "2026-10-29T12:00:00Z",
      "type": "login_success",
      "actor": "account-recorded-in-source",
      "ip": "192.0.2.10",
      "action": "SSH authentication accepted",
      "metadata": {"service": "sshd"}
    }
  ],
  "sources": [
    {"source_id": "server-owned-by-you", "last_seen": "2026-10-29T12:00:00Z"}
  ],
  "truncated": false
}
```

العنوان الوارد في المثال مخصص للتوثيق ولا يدل على زائر حقيقي. الأنواع المدعومة: `login_success` و`login_failed` و`logout` و`http_request` و`process`. الحقول `actor` و`ip` و`session_id` و`action` اختيارية وقيمتها النصية أو `null`. يجب أن تكون الأوقات ISO مع منطقة زمنية. تعرض الصفحة أحدث150 حدثًا ضمن آخر7 أيام، وتستبعد الأقدم والتكرار بحسب المصدر ومعرّف الحدث. الإحصاءات تخص الأحداث المحملة، وليس السجل الكامل.

تُربط تفاصيل الجلسة بحسب `source_id` و`session_id` معًا فقط. إذا غاب معرّف الجلسة يظهر الحدث وحده؛ لا تُستنتج جلسة أو هوية شخص من عنوان IP مشترك. `process` يعني حدث تنفيذ سجله مصدر تدقيق زوّدت الخدمة به، ولا ينفذ البرنامج أوامر أو يجمع العمليات تلقائيًا.

## الاستيراد المحلي

يمكن استيراد ملف JSON بنفس صيغة الاستجابة. `events` مطلوبة و`sources` اختيارية في الملف فقط؛ إن غابت تُستخرج أسماء المصادر وآخر أوقاتها من الأحداث. حد الملف1 ميبيبايت و2000 حدث و100 مصدر قبل التصفية. تُرفض الحقول والأنواع والأوقات وعناوين IP غير الصالحة، ولا يُغيّر ملف مرفوض العرض الحالي. تُستخدم أحدث150 حدثًا ضمن آخر7 أيام بعد التحقق.

لا يُرفع الملف إلى أي جهة. يفصل الاستيراد الاتصال الحي ويمسح رمزه، وتظهر علامة «مستورد · غير حي». العرض التجريبي منفصل أيضًا، ولا يبدأ تلقائيًا. لا يجري بحث موقع في عرض تجريبي أو مستورد، ولا تُرسل أحداثه إلى خدمة. مسح العرض المحلي أو إغلاق الصفحة يزيله؛ ملف CSV الذي تختار تنزيله يبقى على جهازك.

## الموقع التقريبي

عند اتصال حي فقط، يمكن الضغط على البحث في تفاصيل عنوان IP. يوضح الزر أن الخدمة قد ترسل هذا العنوان إلى `ipapi.co` لتقدير المنطقة. تدعم الخدمة الاختيارية:

```http
GET /api/geo?ip=8.8.8.8
Authorization: Bearer <read-token>
```

```json
{"city":"Example","region":"Example","country":"Example","latitude":25.0,"longitude":45.0,"approximate":true}
```

لا يظهر رابط خرائط Google إلا بعد نجاح استجابة تقريبية صالحة بإحداثيات محدودة المجال. هذه إحداثيات منطقة أو مزود خدمة؛ لا تكشف عنوان المنزل، ولا تثبت هوية شخص، ولا تضمن كشف مصدر خلف VPN. إذا لم توفر خدمتك هذا المسار، تظل بقية اللوحة تعمل.

## حالة الخادم وChatGPT

الخادم المعروف `JAWAFFASVR` يعمل بنظام Windows. لم تُهيّأ مراقبة تسجيلات دخوله بهذه الهجرة. لا تغيّر الواجهة نمط الاتصال الصادر فقط في البنية الحالية ولا تفتح منافذ عليه. موصّل SSH المتاح للتنزيل مخصص لـLinux، ويحتاج Windows إلى موصّل مناسب لسجلاته أو تصدير مُطبّع بالصيغة أعلاه.

تعرض لوحة حساب ChatGPT إرشادات الأمان الرسمية فقط؛ لا تقرأ سجلات دخول الحساب الشخصي. الربط المؤسسي عبر منصة الامتثال يحتاج صلاحيات وإعدادًا منفصلين ولم يُهيّأ هنا.

## التحقق المحلي

```sh
node --test dashboard/aman-monitor/tests/*.test.mjs
```

يمكن تقديم مجلد `dashboard/` عبر خادم ملفات محلي لاختبار الواجهة. لا تضع رموزًا أو سجلات فعلية في ملفات الاختبار أو في هذا المجلد العام.


## الدمج المباشر وإدارة الرموز

المسار `aman-monitor/` القديم يعيد إلى `../index.html#jawafa-monitor`. تحمل القيادة `central.mjs` و`template.html` في مكوّن أصلي بداخل Shadow DOM لعزل الأسماء والأنماط، مع إبقاء وظائف البحث والتصفية والتفاصيل وتسلسل الجلسة والتصدير والبحث التقريبي والتجربة والاستيراد والتنبيهات وإيقاف التحديث.

عند اختيار «اتصال بحساب القيادة المركزية»، تحصل الوحدة على Firebase ID token الحالي وتتحقق منه خدمة أمان الخاصة بتوقيع حقيقي وحساب المالك. لا تنفذ الواجهة تحقق البريد بدلًا من الخادم. لا يُحفظ الرمز في الملفات أو التخزين المحلي، ويُحدّث عند كل طلب. الخدمة نُشرت لكن اتصال قاعدتها يفشل حاليًا؛ لم تُفعل مراقبة حية بعد. التفاصيل في `access-monitor-cloud/README.ar.md` بالمستودع.

تعرض إدارة الجامع حالة المفتاح وتوليده أو استبداله وإلغائه. يلزم حساب المالك في الخدمة السحابية، أو `AMAN_ADMIN_TOKEN` مستقل للخدمة الخاصة. لا تُستخدم صلاحية القراءة للتوليد. تعرض القيمة الجديدة مرة واحدة، مخفية افتراضيًا، وتُمسح بعد5دقائق أو مغادرة القسم. تنزيل عنوان الإرسال لا يتضمن الرمز.

تستخدم الإدارة المسارات `GET /api/collector-key/status` و`POST /api/collector-key` بجسم `{"source_id":"your-server"}` و`POST /api/collector-key/revoke` بجسم `{}`. تبقى بادئة عنوان الخدمة محفوظة. تدوير الرمز اليدوي في الخدمة السحابية لا يمس رمز Windows المستقل؛ في الخدمة المحلية يستبدل الرمز اليدوي أيضًا رمز الإقلاع القديم من البيئة.

تظهر إشعارات وصول أحداث جديدة في الصفحة بعد أول تحميل ناجح؛ لا تُحسب إعادة تحميل الأحداث نفسها كدخول جديد. لا يوجد وعد بإشعارات نظام تشغيل أو بريد أو مراقبة في المتصفح المغلق.

أُرفقت ملفات Windows الثلاثة ودليلها في `downloads/`. نجح اختبارها الاصطناعي على الخادم، ولم تُثبّت مهمة أو تُسجّل بيانات فعلية مع تعطل قاعدة المراقبة.

اختبار المتصفح الاصطناعي: `node dashboard/aman-monitor/tests/native-browser.cjs` (يلزم Playwright ومتصفح Chromium مثبتان).
