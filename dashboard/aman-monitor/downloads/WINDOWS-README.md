# موصّل Windows لأمان

نجح تحليل الملفات الثلاثة والاختبار الاصطناعي لـ`Aman-Collect.ps1 -SelfTest` على PowerShell5.1 في JAWAFFASVR. أكد فحص منفصل قابلية قراءة سجل Security فقط؛ لم ينشر محتوى السجل. **لم تُثبت مهمة جمع، ولم يُنشأ رمز جهاز، ولم يُدّع وصول أحداث حقيقية** لأن قاعدة خدمة المراقبة ترفض الاتصال حاليًا.

## طريقة الجمع

يقرأ الجامع الأحداث4624 و4625 و4634 و4647. يمكن إضافة4688 بـ`-IncludeProcess` إن كانت موجودة أصلًا؛ لا يفعّل سياسات التدقيق ولا يجمع سطر أوامر العملية. يربط الجلسة فقط بمعرف LogonId المسجل والمصدر، ولا يربط الأحداث من عنوانIP وحده. قد تمثل الأحداث حسابات خدمة أو دخولًا محليًا، ولا تعني أن كل صف شخص جديد.

يصحح وقت العرض تقديريًا باستخدام `/api/time` مع حفظ وقت Windows الأصلي ومعرف السجل وفرق الساعة. لا يغير ساعة الخادم. معرف الحدث يجمع EventRecordID والوقت الأصلي والنوع لتجنب اصطدام المعرفات بعد إعادة تعيين السجل.

يحفظ طابورًا محليًا ذريًا بحد20000 حدث و20MiB، ولا يحذف الدفعة إلا بعد `ok:true`. يتوقف عن القراءة عند امتلاء الطابور، وقد تُفقد أحداث في المصدر إذا استمر الانقطاع حتى تدوير سجل Windows. يستخدم HTTPS صادرًا فقط، دون إعادة توجيه أو تعطيل تحقق الشهادة. لا يفتح منافذ ولا يعدل قواعد البيانات المالية.

## التهيئة بعد استعادة الخدمة

شغّل كمسؤول:

```powershell
.\Initialize-Aman.ps1 -SourceId JAWAFFASVR
```

ينشئ رمزًا عشوائيًا داخل `%ProgramData%\AmanAccessMonitor`، مشفرًا بـDPAPI LocalMachine داخل مجلد لا يملك الوصول إليه إلا SYSTEM وAdministrators. المخرجات هي الملخص العام والمسار فقط. لا تُلصق الرمز في أدوات أو محادثات. لا تمثل حماية LocalMachine حماية من مسؤول الجهاز نفسه.

سجّل الملخص في الخدمة وفق دليلها، وانسخ الملفات المراجعة إلى المجلد المحمي. أول تشغيل يبدأ من نهاية السجل، ويمكن طلب رجوع محدود صراحة:

```powershell
.\Aman-Collect.ps1 -Once -BackfillMinutes 10
```

بعد نجاح إقرار فعلي، شغّل `Install-AmanTask.ps1`. يرفض المثبّت إنشاء المهمة إذا لم تعمل قاعدة البيانات أو لم ينجح إرسال مصادق عليه، ويرفض استبدال مهمة موجودة دون مراجعتها. ينشئ مهمة مستقلة باسم `AmanAccessMonitor` بهوية SYSTEM، ولا يلمس مهمة RSA أو المهام السابقة. لا تُشغّل نسختين يدويتين من الجامع على الطابور نفسه.

لإيقاف الجمع مع الحفاظ على الطابور: `Stop-ScheduledTask -TaskName AmanAccessMonitor` ثم `Disable-ScheduledTask -TaskName AmanAccessMonitor`.
