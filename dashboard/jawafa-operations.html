استقبال بيانات الفحص

READ ONLY / LOCAL MEMORY

استيراد ملفات CSV أو JSON بعد التحقق من اكتمال التصدير وسلامة المصدر. يجري حساب SHA-256 للملف في المتصفح. لا تُفتح ملفات جزئية أو CSV شديد الحجم.

لا يؤدي استيراد الملف إلى اعتباره نسخة مقبولة. قبول النسخة يتطلب سجل تحقق مستقل: عدد السجلات، اكتمال الملفات، SHA-256، المفاتيح، التوقيت وأخطاء التصدير. هذا النموذج لا يملك صلاحية اعتماد تلك البوابة.

سجل مصادر الجلسة

لا توجد ملفات مستوردة.

مراقبة دفاتر الشيكات

رقم الدفتر، أول وآخر شيك، المستفيد، القيمة، تاريخ التحرير، الاستحقاق، حالة التسليم والصرف والإلغاء.

قيد تدقيق: دفتر شيكات جديد من 50 ورقة أوشك على النفاد وفق إفادة أولية. عدد الأوراق المصروفة أو قيمة الالتزامات غير مثبتين بعد.

البنك والتسويات

التحقق من الحركات البنكية والشيكات المعكوسة والمرتجعات والرسوم وأرقام مرجع الصرف.

المطابقة البنكية الجديدة مقفلة إلى حين إغلاق GATE-15 بدليل مقبول.

الأستاذ العام والقيود

شاشات فحص السندات، فك القيود، التسجيل، التصحيحات، حسابات العملاء والموردين، والخزينة.

المشتريات والطلبات

دورة الطلب والاعتماد والمقارنة السعرية وأوامر الشراء والمخصصات وتحليل الموردين.

الاستلام والمستودعات

مطابقة أمر الشراء والفاتورة وإذن الاستلام وتوثيق النواقص والمردودات وإشعارات الخصم.

المخزون وحركة الأصناف

الاستلام والصرف والتسويات والتالف وفروق الجرد، مع المحافظة على القيم والكمية الأصلية.

الموردون والذمم الدائنة

أرصدة الموردين ومواعيد الاستحقاق والمردودات والخصومات وغرامات التوريد وخيارات التفاوض.

شؤون الموظفين والصلاحيات

ملف الموظف، الوظيفة، الحضور، المستحقات، الصلاحيات وسجل الاستخدام، دون عرض بيانات حساسة على صفحة عامة.

الإسناد الفني يبدأ برقم الجهاز ثم Windows ثم مستخدم TrustSoft ثم الوقت. ظهور اسم مستخدم مشترك لا يثبت هوية المنفذ منفردًا.

خريطة الالتزامات والسيولة

جدولة الدفعات، شهور الاستحقاق، أولويات الموردين، واحتمالات نقص السيولة من البيانات المعتمدة.

التحليلات المالية الجديدة معلّقة ببوابة GATE-15، ولا يجوز عرض مجموع فعلي دون مصدر مكتمل.

غرفة اجتماعات الوكلاء API

تبادل توصيات مهيكلة، تقييم تضاربها، وإرسال مسودة قرار للمدير العام. لا تُستدعى خدمات AI من المتصفح، ولا توجد مفاتيح API داخل الكود.

قائمة المهام

مركز التقارير الإدارية

أنواع التقارير: الشيكات، الاستحقاقات، المطابقة، الموردون، الاستلام، القيود، صلاحيات المستخدمين، قرارات المدير العام، وسجل مصادر الأدلة.

لا يوجد تقرير أُعد في الجلسة الحالية.

سجل الأدلة وسلامة النسخ

لكل ملف: الاسم، زمن القراءة، تاريخ القطع، بصمة SHA-256، النوع، عدد السجلات، وحالة القبول غير المعتمدة.

لا يوجد مصدر تمت قراءته.
