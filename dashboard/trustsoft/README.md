# TrustSoft داخل القيادة المركزية

المسار المباشر: /Mohammad-Ahmed-Ghannam/#jawafa-trustsoft، والواجهة المستقلة على ./trustsoft/.
الواجهة من مشروع Amer-ai-store/Guava، وخدمة API وD1 ووكيل Windows تبقى على Cloudflare.
يصدر تسجيل الدخول جلسة موقعة مدتها15دقيقة تُحفظ في الذاكرة فقط؛ لا أسرار أو بيانات مالية في ملفات Pages.
تُحذف جلسة العرض عند الخروج أو إغلاق الإطار أو مغادرة القسم. إعادة فتحه تتطلب تسجيل دخول جديدًا.
CORS مقيد بالأصل https://amer-ai-store.github.io، ولا تُستخدم ملفات ارتباط طرف ثالث.
المسار تحت هذا الأصل ليس حد أمان مستقلًا عن بقية مستودعات الحساب.
نجاح نشر الواجهة والدخول لا يثبت اتصال JAWAFFASVR أو SQL؛ راجع حالة الوكيل ونتائج الفحوص.
مرجع AppDeploy السابق محفوظ في قسم التسليم التاريخي؛ هذا نقل لواجهة Guava الحالية.
