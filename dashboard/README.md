# مركز قيادة عامر

مركز قيادة لمشروع Amer AI Store في ملف HTML واحد (`index.html`)، على نمط لوحة ChatGPT
«amer-ai-command-center». يجمع إدارة المشروع ولوحة المتجر في صفحة واحدة.

النسخة المنشورة: https://claude.ai/artifact/E8woaJS84Uy99NpG8xWe19 (كل قسم له رابط، مثل `#advisor` و`#tasks`).

## الأقسام

| القسم | الوظيفة |
|---|---|
| مركز القيادة | مؤشرات المهام والبوابات، مهام ذات أولوية، تنبيهات المتجر، آخر نشاط |
| المهام | لوحة بخمس حالات، أولوية، مساحة عمل ومسار تنفيذ يختارهما الذكاء الاصطناعي، مسؤول، بحث وتصفية |
| مراحل التنفيذ | مسارات من بوابات (بانتظار / معتمدة / مرفوضة) |
| مساحات العمل | تجميع المهام والمسارات لكل جزء من المشروع |
| الهيكل وخريطة العمل | شجرة تُرسم تلقائياً من المساحات والمهام والمسارات |
| فريق الوكلاء | الوكلاء والأشخاص ومهامهم المفتوحة |
| المستشار والمحادثة | محادثة مع Claude يقرأ فيها حالة المشروع، وتوصيات جاهزة، واقتراح مهام تُضاف بضغطة |
| لوحة المتجر | الطلبات والمخزون والنزاعات والتحكيم الذكي والمستخدمون، من ملف تصدير التطبيق |
| قاعدة البيانات | المجموعات المحفوظة، وجسور قواعد البيانات الخارجية (وصف فقط) |
| الخوادم والربط | سجل الخوادم ومساراتها واسم متغير المفتاح (لا قيمته) |
| مستودع GitHub | روابط الكود وطلبات الدمج وActions |
| سجل النشاط | آخر 200 تعديل |
| الإعدادات | اسم المشروع والمستودع والفرع |

## أين تُحفظ البيانات

- **داخل Claude:** في قاعدة بيانات مشتركة خاصة بالصفحة. تراها من أي جهاز، ويراها من تشاركه الرابط، والتعديل لمالكها ومحرريها.
- **خارج Claude** (فتح الملف مباشرة في متصفح): في متصفحك فقط، مع شريط ينبّه لذلك.
- **بيانات المتجر المستوردة** تبقى في متصفحك فقط في الحالتين، لأنها تحتوي بيانات مستخدمين.

لا تُحفظ كلمات مرور ولا مفاتيح في أي قسم. الصفحة لا تتصل بالخوادم ولا بـ GitHub، فحالة الخوادم «غير متحقق» حتى تؤكدها يدوياً.

## الربط بالتطبيق

1. في التطبيق: سجّل الدخول كأدمن، ثم اضغط **«تصدير البيانات للوحة الويب»** في شاشة الأدمن واحفظ `amer-store-export.json`.
2. في مركز القيادة: افتح **لوحة المتجر** واضغط **«استيراد بيانات التطبيق»**.

يبني الملف `MarketViewModel.buildDashboardExport()`، وصيغته:

```json
{ "format": "amer-store-export", "version": 1, "exportedAt": 1761230000000,
  "users": [], "products": [], "orders": [], "chatReports": [] }
```

لا يحتوي الملف البطاقات البنكية ولا السلة ولا سجل البحث، وترفض اللوحة أي ملف قيمة `format` فيه مختلفة.

## المتجر الحي (Firebase)

يرسل التطبيق بياناته إلى Firestore مع كل تغيير (`FirestoreSync`)، وتعرضها «لوحة المتجر» مباشرة بعد تسجيل الدخول بحساب Google الخاص بالمالك.
يعمل ذلك على نسخة GitHub Pages فقط: https://mohammadzxzx1991.github.io/Mohammad-Ahmed-Ghannam/#store
لأن صفحة Claude لا تتصل بالإنترنت. الإعداد خطوة بخطوة في `docs/firebase-setup.md`، وإعدادات الويب في `firebase-config.js`.

## المخطِّط: توزيع المهام بالذكاء الاصطناعي

عند إضافة مهمة أو تعديل عنوانها أو وصفها، يختار الذكاء الاصطناعي مساحة العمل ومسار التنفيذ المناسبين. هذا هو الخيار الافتراضي «🤖 يختارها الذكاء الاصطناعي» في نموذج المهمة.
- يفضّل المساحات والمسارات الموجودة، وينشئ مساحة أو مساراً جديداً إن لم يناسب المهمةَ شيء منها.
- يضيف للمهمة بوابة 📌 في المسار. حين تصبح المهمة «منجزة» تُعتمد البوابة تلقائياً، وإن أُعيد فتح المهمة تعود البوابة «بانتظار».
- يكتب سبب اختياره على بطاقة المهمة، ويسجّل كل توزيع في سجل النشاط.
- زر «🤖 وزّع المهام غير الموزعة» يوزّع كل مهمة مفتوحة بلا مساحة أو بلا مسار، واحدة تلو الأخرى.
- يمكنك دائماً اختيار المساحة والمسار يدوياً بدل الذكاء الاصطناعي.

يعمل التوزيع داخل Claude فقط. المهام التي تضيفها خارج Claude تبقى «🤖 يوزَّع داخل Claude» حتى تفتح المركز هناك.

## الذكاء الاصطناعي

المستشار والتحكيم وحساب العمولات تعمل عند فتح الصفحة داخل Claude فقط، وتطلب موافقتك عند أول استخدام.
في المتصفح العادي تتعطل هذه الأزرار وتعمل بقية الأقسام.
