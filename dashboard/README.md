# لوحة تحكم الويب

نسخة الويب من شاشة الأدمن («لوحة تحكم مالك المنصة») في التطبيق. ملف HTML واحد، يُفتح في أي متصفح دون خادم.

## الربط بالتطبيق

التطبيق يحفظ بياناته على الهاتف (Room/SQLite)، لذلك تنتقل البيانات إلى اللوحة عبر ملف تصدير:

1. في التطبيق: سجّل الدخول كأدمن، ثم في شاشة الأدمن اضغط **«تصدير البيانات للوحة الويب»** واحفظ `amer-store-export.json`.
2. في اللوحة: اضغط **«استيراد بيانات التطبيق»** واختر الملف.

يحتوي الملف على المستخدمين والمنتجات والطلبات والنزاعات. لا يحتوي البطاقات البنكية ولا السلة ولا سجل البحث.
تحفظ اللوحة آخر ملف مستورد في متصفحك فقط، ويمسحه زر «العودة للبيانات التجريبية».

## صيغة الملف

```json
{ "format": "amer-store-export", "version": 1, "exportedAt": 1761230000000,
  "users": [], "products": [], "orders": [], "chatReports": [] }
```

يبنيها `MarketViewModel.buildDashboardExport()`، وترفض اللوحة أي ملف قيمة `format` فيه مختلفة.

## التحليل الذكي

زرّا «إعادة حساب معدل الأرباح» و«بدء التحكيم الذكي» يعملان عند فتح اللوحة داخل Claude فقط. في المتصفح العادي يتعطلان وتعمل بقية الأقسام.
