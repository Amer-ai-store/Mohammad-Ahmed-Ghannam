# خدمة أمان الخاصة

الخدمة الجديدة `aman-access-monitor` مستقلة داخل المشروع الحالي، ولا تعدل وظائف AAS أو بيانات جوافة المالية. تستعمل هوية قاعدة البيانات المدمجة في Edge Functions، ولا تعرضها للواجهة أو لسجلات التشغيل.

## حالة التفعيل في 30 أكتوبر 2026

- نُشر مسار الخدمة، وتحقق وصول JAWAFFASVR إلى `/api/time` عبر HTTPS.
- `/api/health` يؤكد وجود هوية قاعدة البيانات، لكن الاتصال نفسه يفشل بـ`ECONNREFUSED`. فشل أيضًا اتصال أداة SQL وأداة المستشار الأمني للسبب نفسه.
- لم تُنشأ جداول المراقبة بعد، ولم يُسجل رمز جهاز، ولم تُستقبل أحداث حقيقية. لا يصح وصف المراقبة بأنها حية.
- لم تُغيّر منافذ الخادم أو جدار الحماية أو مهمته التشغيلية الموجودة، ولم يُعد تشغيل مشروع البيانات أو إيقافه.

## المصادقة والتخزين

تتحقق الخدمة من توقيع Firebase RS256 بالمفاتيح الرسمية الثابتة، ومن المشروع والمُصدر ومدة الصلاحية والحساب المالك الموثق المستخدم أصلًا في قواعد المستودع. القراءة وإدارة الرمز تتطلبان هذه المصادقة؛ رمز جهاز الجامع يسمح بالإرسال فقط، مع نقطة صحة لا تعيد إلا عدد الأحداث ووقت الإشارة للمصدر نفسه.

يوضع التخزين في `aman_access_v1` خارج Data API العام، مع RLS ومنع صلاحيات `PUBLIC` و`anon` و`authenticated`. يطبّق أول طلب مصادق عليه المخطط الثابت في `schema.sql` داخل معاملة مع قفل خاص بالتطبيق. لا يوجد مسار ينفذ SQL يرسله المستخدم، ولا تمس العملية المخططات أو الجداول الموجودة. المخطط مضمن في `schema.mjs` لأن ملفات Edge تُجمّع عند النشر.

تستخدم عمليات الإرسال والإلغاء والاستبدال قفل المعاملة نفسه لمنع قبول رمز أُلغي بالتزامن. تحفظ الخدمة ملخص SHA-256 فقط. المفتاح اليدوي مستقل عن مفتاح Windows المهيأ على الجهاز، فلا يؤدي استبدال أحدهما لإلغاء الآخر. تظهر قيمة الرمز الجديد مرة واحدة، ولا توجد نقطة لاستعادته.

حد الدفعة 100 حدث و256 KiB. التفرد بحسب المصدر ومعرف الحدث. يحتفظ العرض بأحدث150 حدثًا ضمن7 أيام و25 مصدرًا، مع حد180 KiB لاستجابة القراءة. البحث الجغرافي يدوي لعنوان IPv4 عام فقط، إلى مزود ثابت، دون تمرير أي رمز وصول إليه.

## استكمال التشغيل بعد عودة قاعدة البيانات

1. يجب أن ترجع `/api/health` القيمة `database_available:true` مع نجاح فحص SQL والمستشار الأمني. لا تعالج رفض الاتصال بتعطيل TLS أو نشر قاعدة البيانات للعامة.
2. شغّل تهيئة Windows الموثقة؛ يبقى الرمز مشفرًا على الخادم. لا تنسخ الرمز إلى المحادثة أو المستودع.
3. يوضع **الملخص فقط** في `bootstrap.mjs`، ثم تنشر ملفات الخدمة. يحفظ الإدراج الأول مفتاح الجهاز دون إعادة إحياء مفتاح مُلغى موجود.
4. اختبر `Aman-Collect.ps1 -Once -BackfillMinutes 10` على الخادم، وتحقق من إقرار الدفعة وعدد الأحداث عبر `/api/collector-health` دون نشر محتواها.
5. اتصل بحساب المالك من اللوحة، وتحقق من إشارة حديثة وأحداث فعلية قبل تثبيت المهمة الدائمة.

اختبارات الوظائف النقية: `node --test access-monitor-cloud/core.test.mjs`.

مراجع التنفيذ الرسمية: [أسرار Edge Functions](https://supabase.com/docs/guides/functions/secrets)، [الاتصال المباشر من Edge](https://supabase.com/docs/guides/ai/automatic-embeddings)، [التحقق من Firebase ID tokens](https://firebase.google.com/docs/auth/admin/verify-id-tokens).
