# لُقطة — متجر عربي للهاتف

تطبيق React Native/Expo SDK 57 لـAndroid وiOS، وخادم متجر Node 24 + SQLite، ولوحة إدارة وسائق داخل التطبيق. العربية والاتجاه RTL والدينار الأردني JOD هي الإعدادات الافتراضية. النسخة 1.2.0 **تجريبية**: عند عدم إعداد الخادم تُعرض منتجات نموذجية للاستعراض، ولا يُنشأ طلب وهمي.

اقرأ [التقرير الشامل](reports/COMPREHENSIVE_REPORT_AR.md) و[بحث التطبيقات المرجعية](reports/COMPETITOR_RESEARCH_AR.md) قبل نشر المتجر. يتضمن التقرير ما اختُبر فعلًا، وما يحتاج تكاملًا خارجيًا أو جهازًا حقيقيًا.

## تشغيل محلي مجاني

```sh
npm ci
npm run typecheck
npm run lint
npm test
npm run server:commerce
```

يعمل خادم التجارة افتراضيًا على `127.0.0.1:8787` ويخزن البيانات في `server/data/commerce.sqlite` (متجاهلة من Git). ابدأه لأول مرة بحساب مدير عبر متغيرات البيئة `ADMIN_EMAIL` و`ADMIN_PASSWORD`، ثم غيّر بيانات التشغيل التجريبية واحتفظ بها خارج المستودع. يفضل أن تكون كلمة المرور طويلة وفريدة. لتجربة المتصفح شغّل `npm run web` في عملية أخرى، ثم افتح «اتصال الخادم» واختبر `http://127.0.0.1:8787`.

على هاتف متصل بنفس الشبكة الموثوقة، استخدم عنوان IP الحاسوب بدل `localhost` واضبط `HOST=0.0.0.0` للخادم المحلي؛ تسمح نسخة المعاينة بالاتصال المحلي HTTP، بينما يتطلب الاتصال العام HTTPS. النشر التجاري يتطلب خادمًا دائمًا، شهادة HTTPS، نسخًا احتياطية لقاعدة البيانات، وسياسة تشغيل ومراقبة. ليس هناك خادم إنتاج مرفق داخل APK. [عقد واجهة التجارة](server/API.md) يوضح الطلبات والصلاحيات والبيئة.

## الميزات

- حسابات وتسجيل دخول وأدوار عميل/مدير/سائق، واسترداد برمز يعرض مرة واحدة، وعناوين ومحفظة داخلية ونقاط ولاء وحذف الحساب.
- كتالوج قاعدة بيانات ومتغيرات SKU بمخزون مستقل، بحث عربي وفلاتر، مفضلة متزامنة وسلة وإعادة شراء، وطلبات COD أو من رصيد المحفظة، ومرتجعات ومراجعات ودعم.
- لوحة إدارة للمخزون والأصناف واستيراد CSV/JSON والتراجع الآمن عن أحدث استيراد، والطلبات والقسائم والعملاء والسائقين ومفاتيح وكلاء محددة وتدقيق.
- خريطة OpenStreetMap لموقع السائق والوجهة، وطريق قيادة ووقت تقريبي عند توفر موقع حديث وخدمة OSRM، ووضع ليلي محفوظ.
- مساعد توصية عربي محلي مجاني؛ تكامل OpenAI اختياري يحتاج مفتاحًا خادميًا ولم يُفعّل في البناء المرفق.
- شاشة «ربط مركز القيادة المركزي» تتيح للمدير استيراد ملف مالك لوحة Amer AI Command Center الخاصة على الهاتف، ثم اختبار الوصول والمزامنة اليدوية. لا تُضمّن مفاتيح اللوحة في المصدر أو APK، ولم يثبت اتصال حي بها. رابط GitHub Pages العام لوحة منفصلة؛ عرضها أو تعديلها لا يعني نقل قاعدة بيانات لُقطة إليها.

التكامل مع مخزون خارجي يحتاج عنوان API حقيقيًا وصيغته، وFacebook يحتاج تطبيق Meta وموافقة رسمية. البطاقات وApple Pay وPush والباركود/الصورة/الصوت وAR وتشغيل تطوير الشفرة تلقائيًا غير متاحة في هذه النسخة. لا تُستخدم بيانات المنتجات النموذجية كأسعار بيع حقيقية.

## البناء والتحقق

```sh
npm run typecheck
npm run lint -- --no-cache
npm test
npm run export:web
npm run export:mobile
npx expo prebuild --platform android --no-install
cd android
./gradlew :app:assembleRelease -PreactNativeArchitectures=arm64-v8a,armeabi-v7a -Pexpo.useLegacyPackaging=true -Pandroid.enableMinifyInReleaseBuilds=true -Pandroid.enableShrinkResourcesInReleaseBuilds=true -Pandroid.enableBundleCompression=true
```

ملف التثبيت الناتج هو `android/app/build/outputs/apk/release/app-release.apk`. بناء المعاينة موقّع بمفتاح تطوير؛ تحقق من بصمته وحجمه ومعمارياته في التقرير قبل توزيعه. GitHub Actions في `.github/workflows/android-preview.yml` يعيد بناء النسخة ويرفع APK كـArtifact عند إتاحة الرفع إلى المستودع. لتوزيع إنتاجي استخدم توقيع نشر خاصًا وافحص التوافق مع Google Play.

شفرة iOS مشتركة، لكن لم يُنشأ أو يُختبر IPA؛ يلزم macOS/حساب Apple أو بناء EAS. ملفات JS من `export:mobile` ليست IPA أو APK.
