# التقرير الشامل لتطبيق لُقطة — الإصدار 1.2.0

**تاريخ التحقق:** 30 أكتوبر 2026. **البلد والعملة الافتراضيان:** الأردن والدينار الأردني (JOD).

## الحالة الفعلية

لُقطة تطبيق Expo/React Native للهاتف، وله خادم تجارة Node 24/SQLite ولوحة إدارة وسائق داخل التطبيق. نجحت **57 تجربة آلية محلية من 57** في 30 أكتوبر؛ تغطي الحسابات والطلبات والمخزون والمحفظة والمكافآت والتوصيل والبحث والمساعد وموصل مركز القيادة. الاختبارات المحلية لا تعني أن خادم التجارة منشور، أو أن خدمات الدفع وMeta وOpenAI ومخزون المستخدم متصلة، أو أن جميع سيناريوهات الهاتف أُجريت على جهاز حقيقي.

**المتجر العام المرسل:** [مركز قيادة عامر على GitHub Pages](https://amer-ai-store.github.io/Mohammad-Ahmed-Ghannam/) أعاد HTTP 200 يوم التحقق. تعرض صفحته قسم متجر وإعدادات Firebase للعرض الحي بعد تسجيل مالك Google وتفويض Firestore، وتدعم أيضًا بيانات تجريبية أو استيراد ملف يدوي. وجود الصفحة العامة أو إعداد Firebase لا يثبت وصول هذا التطبيق إلى قاعدة Firebase أو نقل جميع وظائف لوحة الإدارة إليها. GitHub Pages يستضيف واجهة ثابتة؛ تشغيل حسابات لُقطة والطلبات ومخزونها يتطلب خادم التجارة الدائم أو تكاملًا خلفيًا موثقًا.

**مركز القيادة الخاص:** [Amer AI Command Center](https://amer-ai-command-center.eagerlark64.chatgpt.site/#workspaces) يعيد HTTP 401 للزائر غير المسجل، وهو سلوك بوابة المالك. أثبت فحص المصدر المصرح به أن نسخته 10 تحتوي قاعدة Cloudflare D1 ومسار `POST /api/v1/app/sync` الموثق لاستقبال لقطة المنتجات والطلبات. يحتوي تطبيق الهاتف على شاشة لاستيراد ملف اتصال المالك وحفظ رموزه في التخزين الآمن، وفحص الصحة وإرسال لقطة يدوية مع فحص الإيصال. مرت اختبارات الموصل مع استجابات HTTP معزولة، **لكن لم يثبت إيصال استلام حي من هاتف المستخدم**. لا يُدرج أي رمز اتصال أو بيانات عميل في المستودع أو APK.

إن لم يُضبط خادم المتجر في شاشة «اتصال الخادم»، يرى المستخدم كتالوجًا نموذجيًا للاستعراض فقط. لا تُنشئ النسخة دون خادم حسابًا أو طلبًا أو رصيدًا حقيقيًا. بيانات العينة وصورها وأسعارها ليست قائمة بيع معتمدة.

**الوضع المجاني:** التوصية العربية المحلية، الكتالوج النموذجي، الاختبارات، والشفرة متاحة دون رسوم API. فحصت استضافة Railway المتصلة، لكن خطة Free تمنح رصيد تشغيل محدودًا قدره 1 دولار شهريًا ولا تضمن بقاء خدمة Node/SQLite متاحة أو تخزينها الدائم عند نفاده. Supabase وCloudflare D1 متاحان للمراجعة، لكنهما يحتاجان نقل منطق الخادم الحالي واختبار ترحيل قاعدة البيانات قبل اعتبارهما بديلًا فعليًا. لا تتضمن الحزمة خادمًا منشورًا «مجانيًا دائمًا» غير مثبت.

## المزايا المنفذة في الكود

**العميل:** تسجيل وإنشاء حساب، رمز استرداد يعرض مرة واحدة ويُستخدم عند فقد كلمة المرور، ملف وعناوين، بحث عربي بفلاتر وترتيب، متغيرات لون/مقاس لها SKU ومخزون وسعر مستقلان، مفضلة متزامنة، سلة وإعادة شراء مع السعر والمخزون الحاليين، قسائم، طلب بالدفع عند الاستلام أو من المحفظة، سجل وتتبع ومرتجعات وتقييم موثق وإشعارات داخلية ودعم ومحفظة ونقاط ولاء ووضع ليلي وحذف الحساب.

**الإدارة:** منتجات وأصناف وأرشفة، معاينة CSV/JSON واستيراد كميات ذري، التراجع عن أحدث استيراد فقط إذا لم تُغيَّر المنتجات بعده، قسائم وطلبات وسائقون ومرتجعات ومحفظة وإعدادات ومستخدمون وتذاكر وسجل تدقيق. تتيح مفاتيح الوكلاء نطاقات محددة وإبطالًا وطابور طلبات صيانة يطلب دليل اختبار عند إكمال المهمة. **الطابور ليس محرك تطوير أو نشر تلقائي للشفرة.**

**التوصيل:** دور سائق، إسناد الطلب، تحديث حالة التوصيل، مشاركة إحداثيات عند الإذن، خريطة OpenStreetMap للعميل، ووقت آخر تحديث. عند توفر موقع حديث ووجهة بإحداثيات، يطلب التطبيق طريق قيادة من خدمة OSRM العامة ويعرض مسافة ووقت قيادة تقريبيين. إذا فشل المزود، يصرح بذلك ولا يخترع وقت وصول.

**الذكاء الاصطناعي:** توصيات عربية محلية مجانية تستعمل بيانات الكتالوج الحالية وسقف ميزانية JOD. خدمة OpenAI خلف خادم منفصل اختيارية؛ عدم وجود مفتاح خادم مفعّل يعني أنها ليست اتصالًا حيًا في APK.

## ما يلزم لتشغيل المنظومة كاملة

1. نشر خادم التجارة Node 24+ مع SQLite دائمة وHTTPS ونسخ احتياطية، وتعيين حساب مدير أولي بأسرار محفوظة خارج المستودع، ثم اختبار «اتصال الخادم» في APK. الرابط العام على GitHub Pages وحده لا يستضيف هذه الخدمة.
2. تحديد عقد الربط بين لُقطة وقسم المتجر في اللوحة العامة: هل المصدر التشغيلي SQLite أم Firestore، ومفاتيح الصلاحيات ومسارات القراءة والكتابة وطريقة تحويل المنتجات والطلبات والمرتجعات. لا ينبغي عمل نسختين قابلتين للتعديل من المخزون دون حل تعارضات.
3. استيراد ملف اتصال المالك للمركز الخاص من داخل حساب مدير على الجهاز، واختبار الصحة وإيصال المزامنة في الموقع الحي. HTTP 401 من بيئة غير مسجلة لا يمكن تجاوزه بإضافة رابط إلى التطبيق.
4. تزويد API لنظام المخزون الخارجي، وتهيئة Meta عند الرغبة، ومزود الدفع والبريد وPush/شحن حسب الحاجة؛ ثم اختبار كل مزود بحساب مخوّل. لا ترسل كلمات مرور أو مفاتيح سرية داخل المحادثة أو المستودع.
