# مساعد التسوق في لقطة

خادم Node.js 22 أو أحدث دون حزم إضافية. يستدعي OpenAI Responses API، ويستخدم نموذج `gpt-4.1-mini` افتراضيًا. تُرسل الرسالة وآخر ست رسائل إلى OpenAI مع `store: false`؛ لا يُحفظ سجل المحادثة في الخادم. يخضع تعامل المزود مع البيانات لسياسات حساب OpenAI.

## التشغيل

من جذر المشروع، بعد إكمال إعداد المفتاح الآمن في `.env.local`:

```sh
node --env-file=.env.local server/assistant.mjs
```

أو عند توفير `OPENAI_API_KEY` في بيئة الخادم:

```sh
node server/assistant.mjs
```

لا تنسخ المفتاح إلى تطبيق الهاتف ولا إلى متغير يبدأ بـ `EXPO_PUBLIC_`. ملف `server/.env.example` يشرح الإعدادات، ولا يحتوي على مفتاح. يُضبط `EXPO_PUBLIC_API_URL` في تطبيق الهاتف على عنوان هذا الخادم مثل `http://localhost:3001`. يحتاج الهاتف الحقيقي إلى عنوان جهاز التطوير على الشبكة و`HOST=0.0.0.0`، والخادم المنشور يحتاج إلى HTTPS.

افتراضيًا يستمع الخادم على `127.0.0.1:3001`. يُحدد `ALLOWED_ORIGINS` مصادر المتصفح المسموحة بدقة، مفصولة بفواصل، مثل `http://localhost:8081`. لا توجد نجمة CORS افتراضية. يقبل تطبيق الهاتف الطلبات دون ترويسة Origin. لا يعتمد الخادم على `X-Forwarded-For`؛ خلف وكيل تشارك الطلبات حد عنوان الوكيل. قبل إتاحته للعامة، أضف مصادقة مستخدمين وحصصًا لكل حساب وحدود إنفاق لدى المزود؛ حدود هذا الخادم ملائمة للتجربة ولا تحل محل تلك الضوابط.

## واجهة الاتصال

`GET /health` يعيد `{ "configured": true }` أو `false` فقط؛ هذا يثبت وجود إعداد المفتاح ولا يثبت صلاحية المفتاح أو الفوترة. لا يُجرى طلب إلى OpenAI من فحص الصحة.

`POST /api/assistant`، مع `Content-Type: application/json`:

```json
{
  "message": "أريد سماعات تحت ٣٠٠ ريال",
  "history": [{ "role": "user", "content": "أبحث عن هدية" }]
}
```

الرسالة مطلوبة وبحد أقصى ١٢٠٠ حرف. السجل اختياري وبحد أقصى ست رسائل، وأدوارها `user` أو `assistant` فقط، وبحد أقصى ١٢٠٠ حرف لكل رسالة.

```json
{
  "message": "هذه خيارات من كتالوج لقطة تناسب طلبك: ...",
  "productIds": ["headphones"],
  "mode": "ai"
}
```

الأخطاء تعيد `{ "error": { "code": "assistant_not_configured", "message": "..." } }`. الحالات تشمل 400 مدخلات غير صحيحة، 403 مصدر غير مسموح، 413 أكثر من 16 KiB، 415 نوع محتوى غير صحيح، 429 حد الطلبات، 503 مفتاح أو كتالوج غير جاهز أو انشغال، 502 خطأ من المزود أو اقتراح غير موثوق، و504 انتهاء مهلة المساعد.

يقرأ الخادم `server/catalog.json` عند تشغيله، ويقبل مصفوفة `{ id, name, price, category, description, tags?, stock? }`. السعر بالريال السعودي. يتجاهل بيانات المنتجات والأسعار التي يرسلها العميل. يختار النموذج معرفات من الكتالوج ضمن JSON Schema؛ تُنشأ أسماء المنتجات وأسعارها ونصوصها من الكتالوج في الخادم. تُطبق الميزانية قبل الطلب وبعده، بما يشمل الأرقام العربية، ويُستبعد المخزون الصفري. حد المساعد ١٥ طلبًا في الدقيقة لكل عنوان شبكة، و٤ طلبات للمزود متزامنة، و١٠٠٠ عنوان في ذاكرة تحديد الطلبات، ومهلة ٢٥ ثانية للمزود. لا تُسجل المفاتيح أو المحادثات أو أخطاء المزود الخام.

## التحقق

```sh
node --test server/assistant.test.mjs
```

تستخدم الاختبارات مفتاحًا وهميًا وبديلًا محليًا لـ `fetch`؛ لا تتصل بـ OpenAI ولا تحتاج إلى مفتاح حقيقي.

توثيق الاتصال الذي رُوجع: [Responses API](https://developers.openai.com/api/reference/resources/responses/methods/create)، [Structured Outputs](https://developers.openai.com/api/docs/guides/structured-outputs)، [GPT-4.1 Mini](https://developers.openai.com/api/docs/models/gpt-4.1-mini).
