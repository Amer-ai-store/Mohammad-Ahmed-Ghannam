# ربط لوحة Amer AI Store المركزية بتطبيق JAWAFA ERP AI

التاريخ: 2026-11-13 · الحالة: **ربط تنقّل تطويري، غير منشور إنتاجيًا**

## نقاط الدخول

- اللوحة المركزية العامة: https://amer-ai-store.github.io/Mohammad-Ahmed-Ghannam/index.html#home
- المسار المضاف في اللوحة نفسها: `#erp-app`، داخل مجموعة «جوافة | المالية والتحقيق».
- شاشة «جوافة 2100» الخضراء الحالية: `#jawafa-2100` (واجهة مرجعية).
- تطبيق ERP مستقل: `jawafa-erp-ai/` مبني بـ Flutter؛ زر شريط العنوان «فتح لوحة القيادة المركزية» يفتح الرابط العام في المتصفح الخارجي، أو ينسخه عند تعذّر الفتح.

## ما تم تنفيذه في الشفرة

1. نقطة دخول من الرئيسية إلى `#erp-app`، ومسار داخل التنقل المكتبي والهاتف.
2. روابط داخلية للأقسام الموجودة للمحاسبة والشيكات والمشتريات والمخزون والموظفين والتقارير.
3. مفتاح رجوع من تطبيق Flutter إلى اللوحة المركزية باستعمال `url_launcher` دون نقل رمز جلسة أو معرّفات أو معاملات.
4. اختبارات مسار اللوحة ووحدة Flutter للتأكد من ظهور روابط التنقل.

## حدود السلامة والقبول

- هذه الوصلة **واجهة تنقّل فقط**؛ لا تُشغّل Flutter داخل GitHub Pages، ولا تنشئ API أو مصادقة أو اتصالًا ماليًا.
- لا توجد إشارة مصدقة إلى أن زر التطبيق مثبت في نسخة APK/EXE منشورة؛ مصدر الكود لا يثبت ذلك.
- لا يُفتح اتصال من المتصفح مباشرة إلى `JAWAFFASVR` أو `Jawafa_DB`، ولا توضع أسرار، أو كلمة مرور `sa`، أو الملف المشفر DPAPI في المستودع العام.
- الاستعلامات المرجعية مستقبلًا تمر فقط عبر واجهة HTTPS خاصة مصادق عليها، وبهوية `user_read` وصلاحيات SELECT مُختبرة، مع فصل جديد ERP مستقل.
- جميع مدخلات ERP المالية وتجارب الشيكات والأرصدة تبقى تجريبية أو غير متاحة حتى الاعتماد. لا تعديل لبيانات TrustSoft أو السجلات المالية أو مخازن النسخ التاريخية.
- لا دمج تلقائي إلى `main` أو نشر إنتاجي تحت تجميد النشر ومراجعة Issue #102؛ PR يبقى للمراجعة حتى فحوص DCO وFlutter واللوحة والأمن والقبول المستقل.

## تحقق مطلوب قبل وصفه ربطًا حيًا

- نجاح اختبارات GitHub Actions الفعلية على طلب الدمج وإثبات DCO.
- اعتماد بنية الخدمة الخلفية وهويتها وتشفير النقل وصلاحياتها وعزل المستأجرات.
- اختبار تشغيلي في بيئة آمنة: جهاز فعلي → زر Flutter → `#erp-app` → شاشة جوافة → عودة.
- اختبار مستقل للقراءة ومنع INSERT/UPDATE/DELETE وقيود الوصول ومراقبة التسرب؛ اعتماد المالك وأمن الإنتاج.

**حقيقة التنفيذ:** اكتمال التنقل برمجيًا لا يعني اكتمال ERP ولا الربط الآمن بقاعدة البيانات، ولا قبول النشر.
